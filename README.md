# my dotfiles
dotfiles i use for my work mac. configured to use sketchybar + aerospace for desktop, tmux + neovim + kitty for workflow

## how to use
dotfiles are modular, you can pick a config for any program and use just that. `stow` is used for managing symlinks.
just write `stow -t ~ -v nvim` to use nvim etc.
